# Docker

Lecture site for Code Platoon Phase I, **Fundamentals: Docker**: what containers are, then writing Dockerfiles, building images, running and cleaning up containers. Hands-on: students type every command in their own terminal.

**Live site:** https://kabeier.github.io/intro-docker/

## Lecture 1: Introduction to Docker (~40 min, 16 slides)

- **Slides:** `lecture-1-intro-to-docker/slides.html`
- **Terminal lab:** `lecture-1-intro-to-docker/terminal-lab/`
- **Activity:** `lecture-1-intro-to-docker/activity-habit-or-trap/`

## Lecture 2: Leveraging Docker (~40 min, 17 slides)

## Instructor kit

- `demo-kit/RUNBOOK.md`: every hands-on step, timings, time checks and backups
- `demo-kit/prompts.md`: every command with its expected output, plus the homework's Claude prompt
- `demo-kit/lecture2-demo/`: the finished Lecture 2 folder (Dockerfile, message.txt, run.sh)
- `demo-kit/pre-pull.sh` · `demo-kit/reset.sh`: before class, and after a dry run
